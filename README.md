# 🐟 摸鱼派扩展脚本 (yupai-extend-js)

为 **摸鱼文化社区——摸鱼派** 开发的一套油猴扩展插件脚本，包含红包助手与聊天增强两大模块，全面提升你的摸鱼体验。

[![Stars](https://img.shields.io/github/stars/mu-xiao-li/yupai-extend-js?style=social)](https://github.com/mu-xiao-li/yupai-extend-js)

## 📌 版本信息
**当前版本：红包板块v1.4.2；快捷功能v2.6.5**

## ✨ 功能特点

### 🧧 红包板块 (`hongbao_module.user.js`)
在页面右侧独立显示一个**红包操作面板**（板块右上角可打开配置），提供完整的红包管理功能。

*   **独立红包面板**：聚合展示所有红包信息，方便统一查看与操作。
*   **自动抢红包**：支持普通红包和猜拳等红包自动抢，可配置**最大金额限制**，避免“抢到-2000”的尴尬。
*   **随机手势**：参与猜拳红包时，自动随机出手势，增加趣味性。
*   **趣味感谢语**：抢到红包后自动发送可定制的趣味感谢消息。
*   **红包屏蔽与抓取**：支持按关键词、发送者等规则屏蔽不想抢的红包，同时精准抓取目标红包。
*   **红包提醒**：新红包出现时进行醒目的视觉闪烁提醒，不再错过任何红包。

### ⚡ 快捷功能 (`quick_functions.user.js`)
在页面左上角提供一个**可拖动的悬浮按钮模块**（右下角紫色小笔按钮可打开按钮配置），深度增强聊天室功能。

*   **快捷回车发送**：使用 `Enter` 键直接发送消息，无需鼠标点击。
*   **快捷消息按钮**：可在线配置常用语按钮，一键发送常用消息。
*   **快捷复读按钮**：一键复读上一条消息，轻松+1。
*   **快捷艾特与引用**：双击头像或消息即可快速 @对方 或引用该消息。
*   **图片消息API支持**：对图片消息API的快捷调用便捷化，可配置专属按钮。
*   **消息小尾巴**：通过插件菜单可为消息添加个性小尾巴（支持趣味小尾巴自选）。
*   **表情包分组**：将聊天室表情包进行分组，查找更方便，更有一键发送表情小按钮。
*   **聊天室红包API支持**：增强红包相关的 API 调用，可快捷发送红包。
*   **批量延迟消息**：支持预设多条消息并按指定延迟时间依次发送。

### ☁️ 消息云·关键词监听 (`message_listening.user.js`)
在页面提供一个**可拖动的悬浮按钮云模块**，点击展开后，可设置监听关键词，以及监听有用户。

*   **关键词监听**：设置关键词，当有人聊天提到时进行提醒。
*   **关键用户发言监听**：当关注用户发言时提醒。
*   **浏览器通知**：开启浏览器通知权限，当有监听消息参数时，推送电脑通知，聚合消息不推送。
*   **监听消息采集**：被监听的消息会自动采集前后5条，点击可查看，原理为dom采集，所以离开页面会丢失。
*   **消息聚合**：可设置一定时间内重复触发同一个关键词时，聚合进去，不进行提醒。
*   **消息弹幕功能**：目前未发布，需要结合java小程序，由于比较卡顿，暂不发布。

## 📥 安装与使用

### 1. 安装油猴扩展
如果你还没有安装 **Tampermonkey**（油猴），请先访问对应浏览器的应用商店进行安装：
*   **Chrome / Edge**: [Tampermonkey](https://www.tampermonkey.net/)
*   **Firefox**: [Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/)
*   其他浏览器请访问 [tampermonkey.net](https://www.tampermonkey.net/)

### 2. 安装脚本
*   在 GitHub 仓库页面，分别点击 `hongbao_module.user.js` 和 `quick_functions.user.js` 文件。
*   进入文件预览页后，点击右上角的 **“Raw”** 按钮，油猴扩展会自动识别并弹出安装窗口。
*   在安装页面点击 **“安装”** 即可。重复上述步骤安装两个脚本。

### 3. 开始使用
*   安装完成后，刷新或重新打开 **摸鱼派社区** 聊天页面。
*   **红包板块**：页面右侧会出现一个独立的红包面板，面板右上角有设置图标，可点击配置各项红包功能。
*   **快捷功能**：页面左上角会出现一个可拖动的悬浮按钮，点击展开功能菜单；右下角的小紫色笔按钮可打开按钮的在线配置界面。

## ⚙️ 配置与自定义

### 红包板块配置
*   通过红包面板右上角的**设置图标**进入配置。
*   可调整的项目通常包括：自动抢红包开关、最大金额限制、随机手势开关、屏蔽关键词列表、提醒方式等。
*   修改后即时生效，无需刷新页面。

### 快捷功能配置
*   **按钮配置**：点击悬浮模块右下角的**紫色小笔图标**，打开配置面板。你可以添加、编辑、删除快捷消息按钮，调整按钮顺序等。配置会自动保存。
*   **小尾巴设置**：通过浏览器的油猴扩展菜单进行设置。
    1.  点击浏览器工具栏的油猴图标。
    2.  在菜单中找到“快捷功能”脚本。
    3.  你可以看到 **“小尾巴开关”** 和 **“更换小尾巴”** 等命令，按提示操作即可。
*   **其他功能**：大部分功能安装后无需额外配置即可使用，如回车发送、双击艾特等。

### 消息监听配置
*   通过消息监听右上角的**设置图标**进入配置。
*   可调整的项目通常包括：关键词、关键用户、聚合时间、是否通知等。
*   弹幕功能需要等待上传。

### 高级自定义（代码级）
如果你熟悉 JavaScript，可以随时通过油猴扩展的编辑器直接修改脚本代码。
1.  点击油猴图标 -> 管理面板。
2.  找到对应的脚本，点击编辑按钮。
3.  在代码顶部或相关区域修改默认参数（如红包默认金额限制、默认快捷消息列表等）。
4.  保存（Ctrl+S）后刷新页面即可生效。
